# Co‑Authors – Multidisciplinary Contributors

The **State‑Building** repository is an open‑source research platform that aims to redesign
the whole architecture of governance, law, ecology and technology.  
We therefore invite **experts from any discipline** to become formal co‑authors.

## How to join

1. **Fork** the repository.
2. **Create or edit** the markdown file that belongs to your discipline  
   (see the table above for file names).
3. Add your contribution **under the project's dual‑license**  
   (AGPL‑3.0 + MIT fallback for code, CC‑BY‑SA 4.0 + AI‑MR‑1.0 for text).
4. Open a **Pull Request** with the title `Co‑author: <Your Name> – <Discipline>`.
5. In the PR description include:
   * Full name, affiliation, ORCID (if any).  
   * A short bio (≤ 150 words).  
   * The specific sections you modify and a **summary of the change**.

All accepted PRs will be merged and the author will be listed in the appropriate
section below.
